Title: Summary of *How to Set Up Claude Cowork the Right Way (So It Actually Does Your Work While You Step Away)* (@heynaytor on X)

**Core Thesis**
- Cowork is a desktop AI collaborator, not a browser chatbot
- The advantage comes from structured context and systems, not clever prompts
- Proper setup enables large portions of knowledge work to run independently
- Prompt engineering depersonalizes → context engineering compounds
- Reads and writes directly to selected local folders

**What Makes Cowork Different**
- Creates .docx files and spreadsheets with working formulas
- Installs specialist plugins by job function
- Loads persistent instructions every session
- Connects to 50+ live tools
- Asks clarifying questions before executing
- Operates inside your real working environment

**File System Access**
- What It Enables
  - Select one folder and grant Claude access during session
  - Reads everything inside that folder
  - Saves outputs directly back into that folder
  - References past reports, spreadsheets, and brand docs automatically
  - Eliminates upload/download loops
  - Turns AI into an embedded collaborator
- Setup Click Flow
  - Download desktop app → Sign in → Subscribe (Pro $20/month or Max $100+) → Open app → Switch to Cowork tab → Select Folder
- Context Files (Highest Leverage Step)
  - Create new folder: Claude Context
    - Add three Markdown files → create them in any text editor → save as .md → place inside Claude Context Folder
    - about-me.md — role, responsibilities, definition of success, example work
    - brand-voice.md — tone, preferred phrases, what sounds wrong, writing samples
    - working-style.md — question-first rule, output length, format defaults, constraints
    - Refine and update them weekly
- First Prompt
  - Read all files in this folder completely
  - Summarize what you know about me, how I work, and available context
  - Why It Matters
    - Prevents confident misinterpretation
    - Forces structured clarification before execution
    - Aligns on scope and approach
    - Reduces hallucination on complex tasks

**AskUserQuestion (Activated via Prompt Instruction)**
- Why It Matters
  - I want to [TASK] so that [WHAT GOOD LOOKS LIKE]
  - First, read all files in this folder completely
  - DO NOT start executing yet
  - Ask me clarifying questions on the approach
  - Only begin work once we've aligned
- Purpose
  - Pre-built specialist packs
  - Add slash commands and structured workflows
  - Convert Claude from generalist to domain-aware operator

**Plugins**
- All 11 Official Plugins (January 2026)
  - Productivity — task management and workflows
  - Marketing — content drafting and campaigns
  - Sales — account research and outreach
  - Finance — financial modeling and reporting
  - Data Analysis — SQL and dashboards
  - Legal — contract review and drafting
  - Product Management — specs and roadmaps
  - Customer Support — ticket handling
  - Enterprise Search — cross-tool search
  - Biology Research — scientific literature and insights
  - Additional plugins continuously added
- Install Click Flow
  - Open Cowork → Click + in chat bar → Click Plugins → Install plugin → Type /to view slash commands
- Example Slash Commands
  - /productivity-start → review tasks → build daily plan
  - /marketing-draft-content → goal → brand-voice.md
  - /data-explore → analyze CSV → flag anomalies → suggest analyses

**Instructions (Persistent Memory Layer)**
- Why They Matter
  - No cross-session memory by default
  - Instructions auto-load every session
  - Global applies everywhere
  - Folder applies per project
  - Eliminates repeated re-explanation
- What to Include in Global Instructions
  - Name and role
  - Communication preferences
  - Output defaults (e.g., always save as PDF)
  - Working rules (always ask clarifying questions first)
  - Constraints and avoidances
- Setup Click Flow
  - Settings → General → Edit Global Instructions → Save
- Folder Instructions
  - Attach client or project brief to folder
  - Automatically loads when folder selected
  - Ideal for repeat client work
- Validation Prompt
  - Before we start any work, tell me what you know about me, how I work, and any standing preferences

**Connectors**
- What They Enable
  - Live integration with 50+ tools
  - Eliminates copy-paste workflows
  - Pulls real-time data directly into sessions
  - Free on all plans
- Examples of Tools
  - Slack
  - Google Drive
  - Notion
  - Figma
  - Asana
  - Many others
- Setup Click Flow
  - Settings → Connectors → Select tool → Add → Authenticate
- Example Prompts
  - Search my Slack messages from the last 7 days and summarize follow-ups organized by urgency
  - Find the most recent document about [project name] in Drive → read → extract key insights

**Cowork Limitations**
- No cross-session memory
- Tasks stop if the app closes
- Higher usage consumption for complex workflows
- Desktop only
- No device sync
- Image generation
- It's still a research preview
- Enable deletion protection
- Review execution plans before sensitive actions

**Your First 30 Minutes**
- Minutes 0–5 Install
  - Download Claude desktop app → Sign in → Subscribe → Open App → Switch to Cowork tab
- Minutes 5–10 Create Context
  - Create Claude Context folder
  - Add about-me.md
  - Add brand-voice.md and working-style.md
  - Save as Markdown
- Minutes 10–15 Set Global Instructions
  - Settings → Edit Global Instructions → Paste highlights → Save
- Minutes 15–20 Run First Task
  - Select Claude Context folder
  - Start session
  - Read all files
  - Help me [task]
  - Ask clarifying questions first
  - Align
  - Execute
- Minutes 20–25 Install One Plugin
  - Click + → Plugins → Install relevant plugin → Type / → Test slash command
- Minutes 25–30 Connect One Tool
  - Settings → Connectors → Connect Slack or Drive or Notion → Authenticate → Ask Claude to pull live info

**Strategic Takeaways**
- Build systems, not prompts
- Store identity and preferences in structured files
- Force clarification before execution
- Install plugins aligned with your role
- Set instructions early
- Connect primary tools to remove friction
- Context compounds over time
